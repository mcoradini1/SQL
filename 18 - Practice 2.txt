Exercise 2:  Using database workers produce the bellow commands.
------------------------------------------------------------------------------------------------------------------------
How many professions and workers we have in each category

select profession, count(*) from workers
group by profession
order by count(*);

------------------------------------------------------------------------------------------------------------------------
How many man and women were born after 01/01/1990

select sex, count(*) from workers where data_of_birth > 01/01/1990
group by sex;


------------------------------------------------------------------------------------------------------------------------
List of countries that have more then 13 workers disconcerning Italians:

select nationality, count (*) from workers
group by nationality
having nationality not like 'Italian' and count(*) > 14;


------------------------------------------------------------------------------------------------------------------------
A list grouped by height, showing how many has more than 80kg and are above average height.

select height, count(*), weight from workers
where weight > 70
group by height
having height > (select avg(height) from workers)
order by count(*);
