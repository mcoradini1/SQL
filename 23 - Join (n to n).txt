Exercise 23: Now considering a case of n:n using the Workers and Courses tables.

------------------------------------------------------------------------------------------------------------------------
JOIN (Just Workers to Watch)
------------------------------------------------------------------------------------------------------------------------
select wk.name, fk_courses from workers wk
join watch w
on wk.id = w.fk_workers
order by wk.name;


------------------------------------------------------------------------------------------------------------------------
Join (Workers Watch and Course)
------------------------------------------------------------------------------------------------------------------------

select wk.name, c.course_name from workers wk
join watch w
on wk.id = w.fk_workers
join courses c
on w.id = c.id
order by wk.name;
