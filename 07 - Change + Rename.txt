Example 7: Renaming Columns and Tables Using CHANGE and RENAME
------------------------------------------------------------------------------------------------------------------------
change column old new (+constraints)

alter table people                                                 -- command 1
change column profession profession_new varchar(20);                         -- Wrong
change column profession profession_new varchar(20)not null default = '';    -- Rewrote Correctly

alter table people                                                 -- command 2
rename to people_all;

------------------------------------------------------------------------------------------------------------------------
Detailed Explanation:

When using CHANGE, all column definitions must be rewritten. If it constraints such as NOT NULL or DEFAULT are not
explicitly specified, they are lost. In a table that already contains data, renaming a column without redefining
constraints may cause issues as example 6 advise.

Renaming a table with RENAME TO changes the table name but does not affect its structure or data.
